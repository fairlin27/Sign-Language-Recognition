# Sign Language Recognition System

## Project Description
A Machine Learning Based Real-Time Sign Language Recognition System with Speech Conversion.

## Objective
To recognize sign language gestures using a webcam and convert the recognized gestures into text and speech.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy
- Pandas
- Scikit-learn

## Algorithms
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Random Forest

## Features
- Real-time hand gesture detection
- Sign gesture classification
- Text output
- Speech conversion

## How to Run
1. Install the required Python libraries.
2. Run the project using Python.
3. Allow webcam access.
4. Show the supported hand gestures to the camera.
